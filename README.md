# 守護獸學園 · 班級養成系統

一個為國小教師設計的「**遊戲化班級經營**」工具,把傳統的加分制升級為**虛擬寵物養成系統**——學生每次表現好,可以餵養自己的台灣特有種守護獸,從蛋孵化成神獸。

> 為什麼是台灣特有種?因為它們本身就是教材。每個孩子養著的是真實存在的、瀕危的、需要被認識的這片土地的居民。

---

## ✨ 為什麼自己做?

過去要做這樣的系統,要學 HTML、CSS、JavaScript、資料庫、後端伺服器,**至少半年起跳**。所以老師只能用現成的、忍受三個限制:

- **免費版的天花板**:學生數受限、進階功能要付費
- **無法客製化**:寵物就是那幾隻、規則就是那幾條
- **資料不是你的**:存在別人的伺服器,服務收掉就消失

這個專案示範的不只是一個系統,而是「**AI 時代,老師也可以是工具創造者**」這件事。

## 🎯 系統功能總覽

**核心:守護獸養成**

8 種台灣特有種(台灣黑熊、石虎、櫻花鉤吻鮭、帝雉、台灣藍鵲、穿山甲、山羌、台灣獼猴)各 4 個成長階段(蛋 → 幼獸 → 成獸 → 守護神獸)。

積分雙軌制:**累積經驗**(寵物進化用,只增不減) vs **可用積分**(商店消費用)。

健康機制:超過 3 天沒被關注的學生,寵物會「微恙」;超過 7 天會「生病」。系統會自動把這些孩子列入「需要關心」清單。

**老師端**

| 分頁 | 功能 |
|---|---|
| 老師後台 | 學生列表、寵物展示、即時積分發放 |
| 課堂工具 | 點名出席、抽籤機(可優先抽生病寵物)、計時器 |
| 聯絡簿 | 今日自動匯整、老師留言、個別備註、可列印 |
| 班級管理 | 拖曳式座位表、隨機/手動分組 |
| 線上測驗 | 出題、Excel 一鍵匯入題庫、開放作答、自動批改結算 |
| 領地佔領戰 | 分組對抗的即時佔領遊戲(見下方) |
| 獎品商店 | 老師自訂獎品與點數、學生自行兌換、老師確認發放 |
| 班級任務 | 全班共同目標與獎勵 |
| AI 助手 | 評語生成、訊息潤飾、行為觀察分析(需自備 API Key) |
| 投影模式 | 教室大屏全班寵物展示,發分時有動畫 |
| 積分規則 | 可自訂 |
| 總覽報表 | 班級概況 + 個人學期成長報告(可列印) |
| 設定 | 班級資料、Excel 匯入、AI Key、危險區 |

**學生端**(雲端模式,Google 登入後直接進入)

| 分頁 | 功能 |
|---|---|
| 我的守護獸 | 自己挑選物種、看進化階段與雙軌積分 |
| 排行榜 | 前三名頒獎台(台高依分差變化)+ 自己名次;有分組時另有小組榜 |
| 測驗 | 作答,答對由系統即時判定加分 |
| 商店 | 用可用積分兌換老師開的獎品 |
| 領地戰 | 分組後才出現,答題搶格子 |

**線上測驗的兩種計分模式**

- **答對就得分**:每個答對的人都拿到分數,適合個人作業與隨堂練習
- **逐題搶答:每題前 N 名得分**:課堂搶答用。學生一題一題往下答,每一題各自比快 ——
  第 1 題最快答對的前 N 位得分,第 2 題重新比一次。一題一份作答文件、只能建立不能修改,
  時間戳由伺服器蓋,所以順序偽造不了,同一題也只能答一次。
- **整份測驗前 N 名得分**:先比答對總題數,同分時先交卷的在前,取前 N 名。

先後順序一律由 Firestore 的伺服器時間戳決定,不看學生裝置的時鐘,
所以同時大量答對也不會亂序或重複給分。

還可以設定**統一結算時間**(日期 + 24 小時制的時間,例如今晚 00:00):時間到之前只記錄交卷順序,
畫面上只顯示「已交卷」;時間一到,老師開啟系統就一次批改、一次排名次、一次發分。
搶答不必邊收邊算,名次也不會因為分批結算而變動。

成績公布後,學生看得到自己答對幾題、名次,以及每一題的 ✓ / ✗ —— 但看不到正確答案。

**領地佔領戰**(分組後才能玩)

蜂窩狀大地圖,各組從自己的基地往外答題擴張。

- **題目與答案老師事先設定好**,誰先答對、誰佔到格子完全由系統判定,老師不必當裁判
- **難度決定佔領分**,格子要累積到門檻才易主;別組的格子也能打,設定時間內誰積分高誰拿走
- **8 種地圖形狀**(六角、矩形、環、十字、星、群島、洞窟、世界地圖)× 5 種尺寸,
  最大 2000 格以上,夠打一整個學年
- **階段性開放**:從各組初始領地往外一圈一圈開放,也可以由老師框選多個格子手動開放/封鎖
- 地圖本身不存檔,而是由作答事件依伺服器時間**重播**還原,所以每台裝置看到的戰況一致。
  事件累積到一定量時,狀態列會出現「壓縮戰況」把目前局面存成快照。

## 🚀 快速開始

### 老師(使用者)

1. **下載整個專案**:點 GitHub 右上 `Code` → `Download ZIP`
2. **解壓縮到任意位置**(例如桌面、隨身碟)
3. **雙擊 `index.html`**——用 Chrome 或 Edge 開啟
4. 首次使用會看到設定畫面,輸入班級名稱、老師稱呼,然後:
   - 直接點「載入示範資料」看完整功能 demo
   - 或從 `assets/學生資料範本.xlsx` 編輯後匯入自己班級
   - 或手動輸入學生名單

5. **存到隨身碟、雲端硬碟、或學校電腦桌面**都可以,完全離線運作

### 老師(進階:讓 AI 幫你)

申請 Anthropic API Key:

1. 至 [console.anthropic.com](https://console.anthropic.com) 註冊
2. 充值 USD $5(約 NT$160,可使用很久)
3. 建立 API Key 並複製
4. 在系統的「**設定**」→ AI 助手區塊貼上 Key 並儲存

然後就能用三個 AI 功能:**評語生成 / 家長訊息潤飾 / 行為觀察分析**。每次使用約 NT$0.1-0.5 元。

### 怎麼修改

想改某個功能?直接打開對應的 `feature-*.js` 檔案,**不用碰其他檔案**。

幾個常見需求:

| 想改什麼 | 改哪個檔案 |
|---|---|
| 換寵物物種(不要台灣特有種,改皮卡丘?) | `js/01-constants.js` 的 `PET_SPECIES` |
| 改進化所需的積分 | `js/01-constants.js` 的 `STAGE_THRESHOLDS` |
| 新增/修改預設獎品 | `js/feature-shop.js` 的 `STARTER_SHOP_ITEMS`(平常直接在商店頁編輯就好) |
| 改領地地圖形狀/尺寸 | `js/feature-territory.js` 的 `MAP_SHAPES` / `MAP_SIZES` |
| 改題目難度對應的佔領分 | `js/feature-territory.js` 的 `DIFFICULTY` |
| 改顏色主題 | `css/base.css` 的 `:root` 變數 |
| 換 AI 模型 / API 設定 | `js/06-ai.js` |
| 改進度條樣式 | `css/dashboard.css` 的 `.progress-*` |

## 🎨 自製寵物圖片(讓系統更有質感)

預設使用 emoji 顯示寵物(🐻 🐱 🐟...),適合先快速開始用。如果想做出有品味的版本,有兩個做法:

**做法 A:放自己的圖**

把 PNG 存到 `assets/pets/`,命名為 `{物種id}-{stage}.png`,例如 `bear-egg.png`、`bear-baby.png`、`bear-adult.png`、`bear-guardian.png`。完整的 32 個檔名列在 `assets/pets/README.md`。

**不用改程式**。系統會自動去找圖,找不到就退回 emoji,所以可以一次只上傳幾張,沒上傳的維持原樣。建議去背存成透明 PNG。

**做法 B:用 emoji 但換主題**

例如要做寶可夢版本,只要改 `01-constants.js`:

```js
const PET_SPECIES = [
  { id: 'pika', name: '皮卡丘', icon: '⚡', desc: '電氣鼠寶可夢' },
  ...
];
```

## 🤖 AI 功能說明

需要自備 Anthropic API Key。三個功能:

**評語生成** — 輸入學生 + 觀察關鍵字 → 系統自動帶入該生的寵物狀態、近兩週積分、主要得分理由給 AI → 產出三種風格的評語草稿(溫暖具體 / 著重成長 / 精簡專業)。

**訊息潤飾** — 老師打草稿(可以很急很口語) + 選擇收件對象與情境 → AI 修飾成可直接寄出的版本,提供三種語氣(溫和 / 中性 / 堅定)。

**行為觀察分析** — 選學生 → 系統自動把這位學生完整的積分歷史、出席、作業繳交、商店消費等資料丟給 AI → 產出四段分析(模式 / 成因假設 / 警訊 / 建議行動)。**這是傳統工具完全做不到的——AI 看到的是時間累積的真實行為資料**。

## ☁️ 雲端版(多班級 + 學生登入)

系統支援兩種運作模式,開啟時自動判斷:

| | 單機模式 | 雲端模式 |
|---|---|---|
| 資料存放 | 這台電腦的瀏覽器 | Firebase Firestore |
| 班級數 | 1 個 | 不限,頂部下拉切換 |
| 學生登入 | 不支援 | Google 帳號,登入後直接進入自己的班級 |
| 線上測驗 | 不支援 | 支援,答對自動加分 |
| 排行榜 / 商店兌換 / 領地戰 | 不支援 | 支援 |
| 費用 | 免費 | 免費(在 Firebase 免費額度內) |

設定方式見 **[docs/雲端設定指南.md](docs/雲端設定指南.md)**,約 20 分鐘。

**30 位學生同時操作為什麼不會亂?**

關鍵在**寫入權責分離**:班級資料只有導師寫得動,學生只能寫「自己那一份」文件
(作答、兌換、選守護獸、領地事件,文件 id 都綁定學生帳號 uid)。
因此再多人同時操作,寫入的位置本來就不同,物理上不可能互相覆蓋。

排序一律用 Firestore 的 `serverTimestamp()`,不信任學生裝置的時鐘,搶答才會公平。

發布給學生的題目不含正確答案;領地戰的答案另存一份學生讀不到的文件,
由 `firestore.rules` 在伺服器端比對後才准許寫入,所以老師不用開著電腦當裁判。
所有權限都是規則強制執行,不是靠前端擋。

## 🔧 技術細節

- 純前端網頁,**單機模式無需後端伺服器**
- 單機模式資料存 localStorage;雲端模式存 Firestore,localStorage 當離線快取
- 使用 [SheetJS](https://sheetjs.com) 解析 Excel
- 字型使用 Google Fonts 的 Noto Serif TC + Noto Sans TC
- Firebase 用 compat SDK 以 `<script>` 載入,**沒有 build 步驟**
- 領地地圖用固定亂數種子(mulberry32)產生,所以同一個班在每台裝置上看到的地形一致

### 為什麼是「無框架」?

刻意不使用 React/Vue 等框架,因為:
1. 老師想客製化時不用學現代前端工具
2. 沒有 build 步驟,純 HTML 雙擊即可開啟
3. 程式碼可讀性高,適合作為教學範例
4. 體積小,網路慢也能用
