# 雲端版設定指南

把守護獸學園從「單機工具」升級為「多班級 + 學生可登入」的雲端系統。
全程免費（Firebase 免費額度對一所小學綽綽有餘），約 20 分鐘完成。

---

## 一、建立 Firebase 專案

1. 到 [console.firebase.google.com](https://console.firebase.google.com) 用 Google 帳號登入
2. 點「建立專案」，名稱自訂
3. **Google Analytics 選「停用」**（不需要，可省下設定步驟）

## 二、註冊網頁應用程式

1. 專案首頁點 `</>` 圖示
2. 暱稱自訂，**不要**勾選 Firebase Hosting
3. 複製出現的 `firebaseConfig` 那一段
4. 貼到 `js/00-firebase.js` 最上方的 `FIREBASE_CONFIG`

> 這段設定可以公開放在 GitHub。Firebase 的安全性由 `firestore.rules` 控管，不是靠隱藏這組金鑰。

## 三、開啟 Google 登入

**Authentication → 開始使用 → Google → 啟用 → 儲存**

填寫「專案公開名稱」與「支援電子郵件」即可。

## 四、建立 Firestore 資料庫

**Firestore Database → 建立資料庫**

- 位置選 **`asia-east1 (Taiwan)`** — 台灣機房，延遲最低
- 先選「測試模式」，下一步會換成正式規則

## 五、貼上安全規則（重要）

**Firestore Database → 規則 分頁**

把專案根目錄 `firestore.rules` 的完整內容貼上，按「發布」。

這一步決定了 30 位學生同時操作時資料不會亂：

| 規則 | 效果 |
|---|---|
| 班級文件只有導師能寫 | 學生改不了任何人的積分 |
| 作答文件 id 綁定學生 uid | 學生只能覆蓋自己那份，交卷永不衝突 |
| 題目學生唯讀 | 學生無法竄改題目 |
| 發布給學生的題目不含答案 | 開發者工具也看不到正確答案 |
| 領地戰的答案存在學生讀不到的文件 | 規則在伺服器端比對答案才准寫入，老師不必在線當裁判 |
| 兌換、選守護獸也是一人一份文件 | 學生無法幫別人兌換或改別人的守護獸 |

## 五之二、把自己設為老師（重要）

老師身分**只能在 Firebase Console 指定**，系統裡沒有「我是老師」這個選項。
這是刻意的：否則任何人用 Google 登入都能建班級，你的 Firebase 額度和資料都暴露在外。

第一次登入之後（登入一次才會產生帳號文件）：

1. **Firestore Database → 資料 分頁 → `users` 集合**
2. 找到你自己的那一份文件（文件 id 就是你的使用者 ID；可以用 email 欄位辨認）
3. 把 **`role`** 欄位的值從 `student` 改成 **`teacher`**
4. 回到系統重新整理，就能建立班級了

要再加一位老師也是同樣做法，把那個人的 `role` 改成 `teacher`。
學生完全不用動，他們的 `role` 一直是 `student`。

> 沒改的話，按「建立班級」會出現權限被拒的訊息，並直接告訴你要去哪裡改。

## 六、授權網域

**Authentication → 設定 → 已授權網域**

- 本機開啟：確認有 `localhost`
- 部署到 GitHub Pages：加上 `znxuyz.github.io`

## 開始使用

### 老師

1. 開啟 `index.html`，用 Google 帳號登入
2. 第一次登入選「我是老師」，建立班級
3. 五個班就重複建立五次，之後用頂部下拉選單切換
4. **設定 → 從 Excel 匯入** 匯入學生名單

**切換班級**

頁首的下拉選單可以直接切班。切換時畫面中央會出現進度提示，逐步顯示
儲存變更 → 中斷上一班連線 → 讀取資料 → 套用名單 → 重新接上同步 → 更新畫面。

提示會擋住畫面直到切完——這是刻意的：切到一半去點別的地方，動到的會是
還沒換完的資料。中途失敗會直接標在失敗的那一步，並把下拉退回原本的班級。

### Excel 名單格式

| 座號 | 姓名 | Google信箱 | 守護獸 |
|---|---|---|---|
| 1 | 王小明 | s1234@ms.school.edu.tw | 台灣黑熊 |
| 2 | 陳美麗 | s1235@ms.school.edu.tw | |

- **姓名**必填
- **Google信箱**是學生自行登入的依據，填縣市帳號。欄位標題寫「信箱」「帳號」「Email」都可以
- **守護獸**留空的話，學生第一次進來可自己挑

匯入後系統會自動同步名冊索引，學生就能登入了。

### 學生

1. 開啟同一個網址，用學校 Google 帳號登入
2. 系統自動比對信箱，**不用選班級，直接進畫面**
3. 上方五個分頁：我的守護獸 / 排行榜 / 測驗 / 商店 / 領地戰
   （排行榜的小組榜與領地戰要老師分好組才會出現）

## 出題與計分流程

```
老師：作業測驗 → 建立測驗 → 新增題目（可用 Excel 匯入題庫）→ 選計分模式 → 開放作答
  ↓
學生：登入 → 看到測驗 → 作答 → 交卷
  ↓
老師：按「收回成績」→ 自動批改 → 加進守護獸與可用積分
```

**題型**：選擇題、是非題、簡答題（簡答題比對時忽略大小寫與空白）

**兩種計分模式**

- **答對就得分**：適合個人作業、隨堂練習
- **逐題搶答：每題前 N 名得分**：課堂搶答用。學生一題一題往下答，送出才看得到
  下一題、不能回頭改；**每一題各自比快**，第 1 題最快答對的前 N 位得分，
  第 2 題重新比一次。每題的時間戳由伺服器蓋，學生無法竄改自己的作答時間，
  而且同一題只能答一次。作答當下不會告訴學生對錯（否則先答的人會把答案傳出去），
  結算後才公布
- **整份測驗前 N 名得分**：先比答對總題數，同分時先交卷的在前，取前 N 名

**統一結算時間（搶答建議用）**

建立測驗時可以填「統一結算日期」＋「結算時間」（小時、分鐘各一個下拉），
旁邊有「今晚 12 點(00:00)」的快捷鍵。

時間一律是 **24 小時制**：`00:00` 是半夜十二點、`12:00` 是中午。
（刻意不用瀏覽器內建的日期時間選單——它的上午／下午是跟著瀏覽器語系跑的、改不掉，
「下午 12:00」到底是中午還是半夜很容易看錯。）

- 填了之後，時間到之前**完全不批改、不發分**，只把交卷順序記在資料庫裡。
  學生畫面上只會看到「已交卷 · ○/○ 公布」
- 時間到之後，**老師一打開系統就會自動一次算完**並公布成績。
  純前端沒有伺服器可以半夜自己醒來，所以動作發生在你開系統的那一刻；
  設半夜十二點是在說「以那個時間為界一次算完」，不是「你要在十二點開電腦」
- 不想等就按測驗卡片上的「提前結算」
- 留空則維持原本的方式：老師自己按「收回成績」

**老師看得到即時作答概況**

測驗開放作答後，卡片下方會列出全班，一人一格、依座號排序：
綠色＝已交卷（逐題搶答是已答完）、黃色＝作答中（顯示答到第幾題）、灰色＝還沒開始。
逐題搶答另外有每一題的作答人數長條，一眼看得出班上卡在哪一題。

這一塊是即時更新的，不必重新整理。如果顯示 ⚠ 而不是人數，表示讀不到作答，
最常見的原因是 `firestore.rules` 還沒重新發布。

**學生看得到自己的答題結果**

成績公布後，學生的測驗卡片會顯示答對幾題、名次（前 N 名模式），
以及每一題的 ✓ / ✗ / —（沒作答）。正確答案不會送到學生端，所以看不到答案。
測驗結束後成績仍然看得到（保留最近幾份）。

**重複結算不會重複加分** — 每位學生每份測驗只會計分一次，老師可以放心多按幾次「收回成績」。

課堂上臨時加分仍然走原本的「老師後台 → 發放積分」，兩邊都會累積到同一隻守護獸。

**積分是雙軌的**：學生每得到一分，同時進到守護獸的累積經驗（只增不減，決定進化）
和可用積分（商店兌換會扣掉）。所以兌換獎品不會害守護獸退化。

## Excel 一鍵匯入題庫

線上測驗與領地佔領戰都可以用 Excel 匯入，欄位相同：

| 題目 | A | B | C | D | 答案 | 難度 | 題型 |
|---|---|---|---|---|---|---|---|
| 台灣最高的山是？ | 玉山 | 雪山 | 大霸尖山 | 合歡山 | A | 簡單 | 選擇 |
| 石虎是保育類動物 | | | | | O | 中等 | 是非 |

- **答案**可以寫 `A`~`D`、`1`~`4`、或直接寫答案文字；是非題寫 `O`/`X`/`對`/`錯` 都可以
- **難度**（領地戰用來決定佔領分）：簡單 / 中等 / 困難
- 在測驗頁或領地戰題庫頁按「下載範本」就能拿到這張表

## 領地佔領戰

分組之後才會出現的即時對抗遊戲。

**老師的準備**
1. 先分好組
2. 匯入或新增題庫，**題目和正確答案都事先設定好**
3. 選地圖形狀與尺寸（最大 2000 格以上，夠打一整個學年），開始遊戲

**進行方式**
- 學生點自己領地旁邊的格子答題，答對就累積佔領分，達門檻才拿下該格
- 難度決定佔領分：困難題一次推進比較多
- 別組的格子也能打，設定時間內誰積分高誰拿走
- 誰先答對完全由系統依伺服器時間判定，老師不用當裁判

**地圖開放**
- 預設從各組初始領地往外一圈一圈開放
- 也可以由老師框選多個格子，手動決定開放或封鎖
- 深色是海（不能走）、米色是已開放的空地、灰色斜線是還沒開放

**戰況壓縮**：地圖不是存檔，而是由所有作答事件重播還原。
打久了事件變多，狀態列會出現「壓縮戰況」按鈕，按下去會把目前局面存成快照，
之後從快照起算。局面完全不變，只是載入變快。

## 資料會不會因為系統更新而消失

不會，但值得知道資料實際上存在哪裡。

**各自獨立存放、任何更新都碰不到的：**
學生交卷、逐題搶答的每一筆作答、領地戰的每一次佔領、兌換申請、學生自選的守護獸。
這些是一人一份（或一題一份）的獨立文件，程式從頭到尾只會新增，不會整批覆寫。

**存在班級那一份文件裡的：**
學生名單與積分、點名、座位表、分組、聯絡簿、作業、商店獎品、班級任務、測驗題目。
這一份每次存檔是整份覆蓋，所以有兩道保護：

1. **不認得的欄位會原封不動帶回去。** 如果你的瀏覽器還快取著舊版的程式，
   它存檔時不會把新版本才有的資料洗掉。
2. **舊分頁不准寫。** 雲端的資料格式比這個分頁新時，系統會停止儲存並要你
   重新整理，寧可不存也不要存錯——存錯救不回來，不存至少雲端還是好的。

**每日快照：**
每天第一次開啟某個班級時，系統會留一份當天的快照，保留最近 30 份。
**設定 → 資料備份** 可以看清單、還原到某一天，也可以下載一份完整備份到自己電腦。
還原前系統會先把現況另存一份，按錯了還有退路。

## 常見問題

**更新名單之後,學生突然不能登入**

檢查名單每一行是不是真的有信箱那一欄。如果整行被當成一個名字
（例如欄位之間用了系統不認得的分隔符號），全班會被當成「新學生」，
舊的那批連同積分與登入權限一起被移除。

現在逗號、頓號、Tab、空白都收，而且要移除已經有積分或守護獸的學生時
會先跳出確認，列出是哪幾位。只打姓名的那一行不會動到原本的座號與信箱。

**學生登入後說「還沒被加入任何班級」**
→ 檢查 Excel 的信箱欄位是否與學生實際 Google 帳號完全一致（含網域）。改好後重新匯入。

**沒有網路怎麼辦**
→ 登入畫面下方有「切換為單機模式」，行為與舊版相同，資料存在這台電腦。

**兩台裝置同時開老師後台**
→ 可以，但同時編輯同一班會以後存的為準。建議一次只在一台裝置操作。

**學生答對了卻沒加到分**
→ 領地戰的答案由安全規則在伺服器端比對，答錯會被拒絕（前端顯示為答錯）。
如果確定答案是對的卻被擋，多半是老師改過題目卻沒重新發布題庫，按一次「發布題庫」即可。

**同一個學生出現在兩個班**
→ 表示這個信箱同時在兩份名冊裡。學生仍會直接進入其中一班，
頁首的班級名稱會變成可切換的下拉選單。要修正就把多餘那班的名單刪掉。

**費用**
→ Firestore 免費額度為每天 5 萬次讀取 / 2 萬次寫入。五個班約 150 位學生，日常使用量遠低於此。
